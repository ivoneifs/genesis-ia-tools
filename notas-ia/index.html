N°02/SUAS CHAVES, SEU CONTROLE

Configure suas chaves de API

Suas chaves ficam salvas apenas no seu navegador. Nunca são enviadas para nossos servidores, nunca aparecem em logs, nunca saem do seu dispositivo.

Como consigo uma chave de API?

OpenAI: acesse platform.openai.com/api-keys e crie uma nova chave. Use o modelo gpt-4o-mini — barato e ótimo para resumos.

OpenRouter: acesse openrouter.ai/keys. Permite usar Claude, Llama, Mistral e outros com uma chave só.
